# Persistence

## Engine & bootstrap

PostgreSQL only. Resolution order ([db.py](../app/infrastructure/persistence/db.py)):

1. `ECON_DATABASE_URL` / `DATABASE_URL` if set.
2. Otherwise an embedded cluster: `initdb`/`pg_ctl` from
   `.mamba/envs/toolchain/bin` (override: `ECON_PG_BIN_DIR`), data in
   `data/pgdata/`, unix socket in `/tmp/econboard-pg-<uid>` (macOS socket
   path length limit), no TCP. Database `econboard`; tests use
   `econboard_test`.

Migrations: Alembic, `migrations/versions/0001_initial_schema.py`
(autogenerated from the ORM, reviewed). The API lifespan and
`econ baseline-create` run `alembic upgrade head` automatically.

## Tables

| Table | Purpose |
|-------|---------|
| `simulation_runs` | UUID PK, status CHECK (PENDING/RUNNING/COMPLETED/FAILED), baseline FK, horizon, error_type/message, timestamps |
| `economic_changes` | 1:1 run — the user's variable/route/type/value |
| `model_versions` | FAIR / TAX_CALCULATOR / LLM version labels + details JSONB |
| `simulation_model_versions` | run ↔ version M:N |
| `model_artifacts` | version FK, name, path, sha256, size — **metadata only, never blobs** |
| `baselines` | name, ACTIVE/RETIRED, Fair version FK, solve window, BASE.BIN artifact FK |
| `baseline_metrics` | 10×14 rows per baseline; unique (baseline, metric, period) |
| `simulation_metrics` | changed-scenario metrics per run; unique (run, metric, period) |
| `metric_deltas` | baseline/changed/absolute/percentage (NULL when baseline=0), unit |
| `tax_calculator_results` | 1:1 run — reform JSONB + weighted aggregates |
| `tax_fair_adapter_results` | 1:1 run — mapping id/method, derived delta, 14-quarter allocation, conversion_metadata JSONB |
| `llm_interpretations` | 1:1 run — model id, prompt version + full prompt/response text, token counts |

All metric/money columns are NUMERIC(24,10).

## State management

Transitions: PENDING→RUNNING|FAILED, RUNNING→COMPLETED|FAILED. Enforced in
`SimulationRunRepository.transition()` by policy check + guarded
`UPDATE … WHERE status=:from` (rowcount 0 → `InvalidStateTransitionError`),
so concurrent/stale writers cannot corrupt state. Startup recovery
(`SimulationWorker.recover_orphans`): RUNNING→FAILED("interrupted"),
PENDING re-enqueued in creation order.

## Provenance

`econ baseline-create` records the Fair program/model labels, sha256 of the
fp binary, all 4 model input files, and BASE.BIN. Each run links to the
model versions used via `simulation_model_versions`.
